# Project Companion release notes

## 0.2.0

Project Companion can now consume hosted connector contract `1.0` when a valid hosted API origin is configured. Pairing, transfers, reads, credential changes, and acknowledgements remain explicit administrator actions. The extension continues to provide its complete local recommendation and preview foundation while disconnected.

## 0.1.0

Project Companion begins with a local-first planning and recommendation foundation. Hosted connection features remain unavailable until an approved connector contract exists.

See the package root `CHANGELOG.md` for the complete change list.
